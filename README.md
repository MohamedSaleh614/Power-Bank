# 🔋 DIY Li-Ion Power Bank

A compact power bank project combining battery charging, protection, and voltage conversion.

### ⚙️ Main Components
- **LTC4054:** Li-ion battery charger
- **BMS:** Battery protection
- **MC34063A:** Boost converter

### 🔌 Working Principle
1. Charge the Li-ion battery through the LTC4054.
2. Use the BMS for battery protection.
3. Boost the battery voltage to 5V using the MC34063A.

### 🎯 Goal
Build a practical power bank using individual electronic circuit stages.

### 🛠️ Project Status
DIY electronics project. Test the output voltage, current capability, and protection functions before connecting devices.
